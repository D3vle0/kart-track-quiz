# Kart Track Quiz (카트라이더 트랙 맞히기)

카트라이더 트랙 퀴즈 웹 애플리케이션입니다.

## 기술 스택
- **Runtime**: Node.js
- **Package Manager**: npm
- **Language**: TypeScript
- **Framework**: Express.js
- **Template Engine**: EJS

## 실행 방법

### 의존성 설치
```bash
npm install
```

### 개발 서버 실행 (핫 리로드)
```bash
npm run dev
```

### 프로덕션 빌드
```bash
npm run build
```

### 서버 실행
```bash
npm start
```
